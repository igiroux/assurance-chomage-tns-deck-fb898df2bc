# Assurance chômage TNS — Deck mémorisation

Deck HTML statique (slides plein écran) pour mémoriser le projet d’**assurance chômage privée pour les TNS** (travailleurs non salariés) en France.

## Contenu

- Vision : filet digne + accompagnement ; client pas fraudeur ; faits pas com’
- Hors UNEDIC salariés (L.5422-13)
- Cible TNS France (Europe plus tard)
- Valeur vs ATI (~600–800 € × 182 j) et vs GSC
- Modèle branche 16 (Code des assurances R.321-1)
- Parcours ACPR : agrément, MCR 2,7 M€ non-vie, SCR, 4 fonctions clés, programme 3 ans
- Risques & 6 prochaines étapes
- One-liner de clôture

## Cloner

```bash
git clone https://github.com/igiroux/assurance-chomage-tns-deck.git
cd assurance-chomage-tns-deck
```

Ouvrir `index.html` dans un navigateur, ou servir en local :

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

Navigation : ← →, Espace, clic (droite = suivant), swipe.
